# My Personal Blog

Hi! My name is Pedro Juan, a developer from Brazil 🇧🇷. Welcome to my project!

I created this repository to share the development of my personal blog, where I will post articles about everything I am learning throughout my journey in technology.

The main idea behind this project is to help people who are starting in the field, while also improving my own skills in software engineering, Linux, DevOps, AI, backend development, and English.

This blog is being built completely by me, including both the frontend and backend. I also decided to write everything manually, without AI-generated text, as a way to practice my communication and writing skills in English.

At first, the platform will be very simple and focused mainly on technical articles and study notes. Over time, I plan to improve the project and continue sharing new things that I learn.

Thank you for visiting this repository!
